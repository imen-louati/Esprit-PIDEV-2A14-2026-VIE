
# Vie - Plateforme de Santé & Accompagnement

# Overview (Aperçu)
Ce projet a été développé dans le cadre du programme de 3ème année d'ingénierie à Esprit School of Engineering – Tunisia (Année universitaire 2025-2026). 
Il s'agit d'une application web complète dédiée à la sensibilisation médicale, la gestion des dossiers, des rendez-vous et des services communautaires de santé.

## Modules & Fonctionnalités
- Module Utilisateur (Tronc commun) : Gestion des comptes, rôles, authentification et profils.
- Formulaires médicaux : Création de questionnaires, gestion des questions et soumission des réponses.
- Dons & Bénévolat : Dons financiers/matériels et suivi des associations partenaires.
- Centres de soins : Gestion des services médicaux spécialisés et recherche géographique.
- Témoignages & Communauté : Publication d'expériences, réactions et modération.
- Campagnes : Création de campagnes de sensibilisation et suivi des participants.
- Articles & Ressources : Publication d'articles médicaux classés par catégories.

## Tech Stack (Technologies)
- Frontend :  HTML5, CSS3, JavaScript
- Backend : PHP / Node.js
- Base de données : MySQL / phpmyadmin
